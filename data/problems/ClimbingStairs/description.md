
# Climbing Stairs

**Difficulty:** Easy

**LeetCode:** https://leetcode.com/problems/climbing-stairs/

## Description

You are climbing a staircase that takes n steps to reach the top. Each time, you can climb either 1 or 2 steps.

Return the number of distinct ways you can climb to the top.

## Input
An integer n representing the number of steps.

## Output
An integer representing the number of distinct ways to reach the top.

## Constraints
- 1 <= n <= 45

## Examples

**Example 1:**
- Input: n = 2
- Output: 2

**Example 2:**
- Input: n = 3
- Output: 3

**Example 3:**
- Input: n = 5
- Output: 8
